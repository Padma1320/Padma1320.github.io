# Padma Muthu Lakshmanan — Portfolio

Static engineering portfolio for GitHub Pages.

## Publish on GitHub Pages

1. Create a **public** repository named `Padma1320.github.io`.
2. Upload everything inside this folder to the repository root.
3. In GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. The site will be available at `https://Padma1320.github.io`.
